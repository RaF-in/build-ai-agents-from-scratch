Production-Grade Logfire Tracing for the AI Agent

OpenTelemetry traces + lightweight metrics, visible in the Logfire UI and console — organized into phases.

Logfire / OpenTelemetry litellm auto-instrumentation Traces + metrics Token-gated & no-op safe telemetry_attributes() on domain objects

Context

The agent runs a deep, mostly-invisible runtime: a turn loop that calls an LLM, dispatches tools, spawns sub-agents, and runs a Planner→Generator→Evaluator (PGE) capability pipeline with parallel worker fan-out — often concurrently. Today the only visibility is rich prints and an ad-hoc per-run JSON log. When a run is slow, expensive, or wrong, there is no navigable, timed record of what happened, in what order, how long it took, and with what data.

This plan introduces Logfire (OpenTelemetry traces + lightweight metrics) as a first-class observability layer: a clean span tree in the Logfire UI and a concise console, with token/cost/error metrics, secret scrubbing, and a strict “telemetry must never break the app” guarantee.

Decisions confirmed with the user
  • Payload detail: summaries/metadata + short previews by default; full payloads only when TRACE_CAPTURE_CONTENT=1.
  • Traces + lightweight metrics (tokens, cost, tool errors, subagent failures).
  • Concise console spans alongside existing rich prints.
  • Token-gated, env-driven: configure once at startup only if LOGFIRE_TOKEN is set; otherwise a full no-op.
What changed in this revision
  • The plan is now broken into 6 phases with sub-phases and a code sketch on each.
  • Adopted the tutorial's pattern: a telemetry_attributes() method on the domain objects themselves (AgentContext, RunBudget, CapabilityConfig) — one source of truth, dotted namespaced keys. telemetry.py only composes/merges them; it no longer owns a separate ctx_attributes() helper.

Target span tree

agent.request               (one user message → completion; root for CLI/Telegram/cron)
└─ agent.turn               (one AgentRuntime.run() call: 1 LLM call + its tool batch)
   ├─ litellm <model>       (auto: litellm's native logfire callback — tokens/latency/cost)
   └─ agent.tool {name}     (one run_tool dispatch)
      └─ capability.pipeline {name}        (entry tool → run_pipeline)
         ├─ capability.phase plan  → agent.subagent role:planner → agent.turn…
         ├─ capability.phase gen   → agent.subagent role:generator
         │     └─ agent.tool DelegateWebSearchTool
         │        └─ capability.delegate (N workers)
         │           └─ agent.subagent worker  (×N, concurrent)
         └─ capability.phase eval  → agent.subagent role:evaluator
   (also nested where relevant): session.compaction

Parentage is automatic: every boundary is an async/await call and asyncio.gather copies the OTel context into each task.

0.2 telemetry_attributes() on the domain objects (the source of truth)

tool_base.py (RunBudget, AgentContext) and capabilities/shared/config.py (CapabilityConfig)

Each domain object knows how to describe itself with dotted, namespaced keys. This is the single place a key like agent.depth or budget.exhausted is defined; spans never hand-build attribute dicts. 

# tool_base.py
class RunBudget:
    def telemetry_attributes(self) -> dict[str, Any]:
        return {
            "budget.calls": self.calls,
            "budget.max_calls": self.max_tool_calls,
            "budget.elapsed_s": round(time.time() - self.started_at, 1),
            "budget.exhausted": self.exhausted(),
        }

class AgentContext:
    def telemetry_attributes(self) -> dict[str, Any]:
        attrs = {
            "agent.depth": self.depth,
            "agent.max_depth": self.max_depth,
            "agent.policy": type(self.policy).__name__ if self.policy else "DefaultPolicy",
        }
        if self.chat_id is not None: attrs["agent.chat_id"] = self.chat_id
        if self.workspace_dir:   attrs["agent.workspace"] = os.path.basename(self.workspace_dir)
        if self.run_budget:      attrs.update(self.run_budget.telemetry_attributes())  # compose
        if self.todo_list and hasattr(self.todo_list, "count_open"):
            attrs["agent.todos.open"] = self.todo_list.count_open()
        return attrs
# capabilities/shared/config.py
class CapabilityConfig:
    def telemetry_attributes(self) -> dict[str, Any]:
        return {
            "capability.name": self.name,      "capability.breadth": self.breadth,
            "capability.max_rounds": self.max_rounds, "capability.verify": self.verify,
        }

0.3 The telemetry.py module (config, safe span wrapper, payload gating, metrics)

telemetry.py (new)

# telemetry.py
import os, json, contextlib, logfire

ENABLED = False
CAPTURE_CONTENT = False
_M = {}  # metric instruments

class _NullSpan:                       # so call sites can always .set_attribute safely
    def set_attribute(self, *a, **k): pass
    def set_attributes(self, *a, **k): pass

def configure_telemetry() -> bool:        # idempotent; call ONCE at startup
    global ENABLED, CAPTURE_CONTENT
    if ENABLED or not os.getenv("LOGFIRE_TOKEN"):
        return ENABLED                       # no token => full no-op (CI/tests/local clean)
    logfire.configure(
        service_name=os.getenv("OTEL_SERVICE_NAME", "ai-agent"),
        environment=os.getenv("AGENT_ENV", "dev"),
        console=False if os.getenv("TRACE_CONSOLE") == "0" else logfire.ConsoleOptions(verbose=False),
        scrubbing=logfire.ScrubbingOptions(extra_patterns=["api_key", "telegram", "tavily", "groq"]),
    )
    import litellm; litellm.callbacks = ["logfire"]   # auto-spans for every LLM call
    _M["tool_errors"] = logfire.metric_counter("tool.errors")
    _M["subagent_failures"] = logfire.metric_counter("subagent.failures")
    _M["llm_tokens"] = logfire.metric_counter("llm.tokens")
    CAPTURE_CONTENT = os.getenv("TRACE_CAPTURE_CONTENT") == "1"
    ENABLED = True
    return True

def span(name: str, **attrs):                # the ONLY way call sites open a span
    return logfire.span(name, **attrs) if ENABLED else contextlib.nullcontext(_NullSpan())

def payload(key: str, value) -> dict:        # summaries by default, full only when CAPTURE_CONTENT
    s = value if isinstance(value, str) else json.dumps(value, default=str)
    if CAPTURE_CONTENT: return {key: s}
    return {f"{key}_bytes": len(s), f"{key}_preview": s[:200]}

def record_tool_error(name): ENABLED and _M["tool_errors"].add(1, {"tool": name})
def record_subagent_failure(name, status): ENABLED and _M["subagent_failures"].add(1, {"role": name, "status": status})
def record_tokens(usage):                  # token metric from data litellm already returned (point 4 safe)
    if not (ENABLED and usage): return
    _M["llm_tokens"].add(getattr(usage, "prompt_tokens", 0), {"kind": "input"})
    _M["llm_tokens"].add(getattr(usage, "completion_tokens", 0), {"kind": "output"})
def instrument_fastapi(app): ENABLED and logfire.instrument_fastapi(app)
Why _NullSpan matters: when telemetry is off, span() still yields an object with no-op set_attribute(), so with telemetry.span(...) as s: s.set_attribute(...) works identically whether or not a token is present. This is the “telemetry must never break the app” rule, enforced structurally.

# agent.py — replaces the 3 duplicated run/while-has_more loops
async def run_to_completion(runtime, user_text, sys_prompt, *, channel):
    with telemetry.span("agent.request",
                        **{"agent.channel": channel, "agent.model": runtime.model_name},
                        **runtime.context.telemetry_attributes()):     # ← source of truth
        has_more = await runtime.run(user_text=user_text, sys_prompt=sys_prompt)
        while has_more:
            has_more = await runtime.run(user_text=None, sys_prompt=None)
